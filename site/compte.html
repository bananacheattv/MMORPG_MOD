Mon compte Aéloria

Un seul compte pour le site, le launcher et la boutique.

Les comptes ouvrent bientôt. En attendant, télécharge le launcher et connecte-toi avec ton compte Microsoft.

Mot de passe oublié ? Dans le launcher, page Compte puis « Mot de passe oublié » : ton compte Microsoft sert de preuve.

3 à 16 caractères : lettres, chiffres ou _.

10 caractères minimum. Une phrase de passe est idéale.

Ensuite, connecte-toi dans le launcher avec ce compte : ton personnage Minecraft sera lié automatiquement.
