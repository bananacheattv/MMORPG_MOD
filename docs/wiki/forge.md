# Forge Arcanique

Réunissez les matériaux, l’or et le niveau indiqués par la recette. Apprenez le parchemin propre à votre équipement lorsqu’il est requis.

Choisissez votre classe et votre équipement dans la forge, puis fabriquez. Les outils peuvent recevoir les améliorations prévues dans le menu dédié.
