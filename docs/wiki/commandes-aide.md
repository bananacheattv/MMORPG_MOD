# Commandes et dépannage

[Accueil du wiki](README.md) · [Commandes et aide](commandes-aide.md)

| Commande / touche | Utilité |
|---|---|
| E | Personnage et inventaire |
| M | Menu MMORPG |
| U | Éditeur de l’interface en jeu |
| `/arene` | Menu des arènes |
| `/arene quitter` | Quitter son arène |
| `/arene bilan` | Revoir le dernier récapitulatif |
| `/pvp` | Marchand à points d’arène |
| `/guilde` | Menu de guilde |
| Échap | Menu de pause Aeloria |

Les raccourcis sont modifiables dans Options > Commandes. Si une touche est déjà utilisée par un autre mod, affecte une touche libre.

**Je ne peux pas utiliser mon arme :** vérifie sa classe, son niveau et le mode de jeu autorisé. **Je ne peux pas parer :** équipe l’arme de Paladin, vérifie son bouclier lié et attends 100 % de garde après une rupture.

**Je n’ai plus de place :** ouvre les sacs ou libère une case. L’or rejoint directement le portefeuille ; un achat PvP plein reste en livraison. **Mon écran est mal disposé :** Personnage > Personnaliser > Réinitialiser, ou U pour les éléments du HUD.

**Je ne vois pas la mise à jour :** ferme le jeu, utilise Mettre à jour dans le launcher puis relance. Les shaders facultatifs se gèrent dans les réglages du launcher puis dans le menu des shaders en jeu.

**Je ne vois pas le bilan :** utilise `/arene bilan` après ton retour. Si le problème persiste, indique s’il s’agissait d’une partie normale, d’un entraînement ou d’une sortie avant la fin, avec la version du launcher et du mod.
