# Aeloria — pack d’illustrations pour les interfaces

**10 PNG : 7 nouveaux visuels et les 3 cartes métiers déjà créées.** Générés avec l’outil intégré `image_gen`, dans la continuité Minecraft MMORPG violet/or validée par l’utilisateur.

➡️ **[Instructions pour Claude](BRIEF_CLAUDE.md)** · [Dimensions, transparence, cadrages et empreintes](manifest.json) · [Prompts exacts des 7 nouvelles générations](prompts.json)

Ce commit livre uniquement des images et leur documentation. Les interfaces ne sont pas encore intégrées par ce pack. Les trois métiers réutilisent les illustrations précédemment créées dans la conversation, sans sous-titre Aeloria ; les sept nouvelles images ne portent aucun texte de menu.
